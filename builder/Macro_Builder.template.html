psi_autocast Macro Builder

Build a one-key psi macro for System Shock 2: 25th Anniversary Remaster with the psi_autocast mod. Add casts in the order you want them. The builder puts the right waits between them, then gives you the macro file and the key binding line.

Works offline. Nothing you enter leaves this page.

Macros are built from the game's console commands. The System Shock wiki's command console page is incomplete: several commands this mod uses aren't listed there. The only complete source is a dump from the game itself. Open the console (Ctrl+;), type help and then dump_cmds, then condump to save the list to condump.txt in the game folder.

1. Settings

These apply to the whole macro, including steps you've already added.

Before each cast, uses a psi hypo if your psi points are at or below your maximum minus what a hypo restores, then waits 500 ms, so none is wasted. A hypo restores 30 on Easy and 20 on Normal, Hard and Impossible, plus 20% with the Pharmo-Friendly O/S upgrade (36 or 24). The mod reads your difficulty and upgrades itself.

How long the Arm psi amp step waits for the amp to come up. 800 ms works when switching from the pistol.

    3. Steps, in order

      No arm step: this macro only works when the psi amp is already in your hands. If it isn't, the chain stops and says so in the console.

      No steps yet. Add one above.

      Waits default to 500 ms. Two casts must be at least 500 ms apart in total, counting any hypo between them, because that's the psi amp's refire limit. Other waits can be shorter.

      Durations come from the game's data, or from its help text where the data has no entry. "Max" uses PSI 8, the highest PSI in the game's overload table. When the step overloads a discipline that benefits, it uses PSI 10, since an overload adds 2 PSI according to the System Shock wiki.

      Install it
      
    
        
      
      1. Save the macro file into the game's psi\chains\ folder (inside the folder containing SystemShock2Remastered.exe). Create the folder if it doesn't exist.
        2. 
      
      2. Close the game, then add the binding line to %USERPROFILE%\Saved Games\Nightdive Studios\System Shock 2 Remastered\user.bnd. Check that the key isn't already bound: search the file for .
        3. 
      
      3. Start the game and press the key. The console (Ctrl+;) reports each step.
        4. 
    
      
    
      Once the binding exists, you can edit the macro file while the game runs. The next keypress uses the new version.
      
    
      To stop a macro partway through, bind a cancel key too: bind <key> "run psi\actions\cancel_macro.txt". It skips the rest of the running macro. A cast that is mid-charge is released, so it casts at normal strength, or fizzles if the charge has only just started.
